Signal & Alignment Funnel

How much of each sample's sequencing actually comes from coffee DNA, before any variant is called.

Pre-trimming baseline, September 19, 2026 — will update once adapter-trimmed re-runs finish.

Why the numbers drop so fast

Every sample starts as tens of millions of raw sequencing reads. Two things happen to that pool before any of it can be used for variant calling:

  • Alignment — each read is checked against the Coffea arabica reference genome. Only reads that actually match are kept; everything else is presumed non-target DNA (environmental or microbial), not analysis error.
  • Deduplication — of the reads that do align, most turn out to be repeated copies of the same small pool of original DNA molecules, a limit set back in the lab during extraction, not by sequencing. Only the unique originals are kept.

Well under 1% of raw reads make it through both steps. That's expected for degraded, shipwreck-recovered DNA sequenced without target enrichment — but it also raised the question of what the other 99%+ actually is. The Metagenomic Screening section below answers that directly.

Metagenomic Screening

Taxonomic classification of sequencing reads against the NCBI reference database, run on the same Vrouw Maria samples.

Preliminary — screened for R0003/R0004 so far; R0002/R0005 pending.

Last updated: September 19, 2026

How it works, roughly

Metagenomic screening classifies every sequencing read against a database of known organisms, so a sample can be checked for DNA beyond the target reference — contaminants, environmental microbes, and the like.

  • It breaks every read into overlapping k-mers (short, fixed-length chunks — 35 base pairs by default).
  • Each k-mer is looked up in a precomputed database: essentially a giant hash table mapping k-mers to the lowest common ancestor (LCA) in the NCBI taxonomy tree of every reference genome that contains that k-mer. A k-mer found only in E. coli maps to E. coli; one shared across all Proteobacteria maps up to that broader group instead.
  • A read gets classified to whichever taxon accumulates the most k-mer "votes" along the tree.
